## Who builds it?

Static Site Generator is written by
[Sebastien Rousseau](https://sebastienrousseau.com/), who is on
[GitHub](https://github.com/sebastienrousseau) as sebastienrousseau. The
first commit was made on 14 March 2023. The project was called Shokunin
until version 0.0.36, released in April 2026.

## How is it versioned?

ssg is pre-1.0 and releases step by 0.0.1 at a time. Only the latest release
receives security fixes. Read the [changelog](/changelog/) before upgrading.

## What is this website?

shokunin.one was the project's website under its old name. It now explains
the rename and points to the current documentation, and it is built with
ssg itself.
